## 1. 项目定位

**烟厂制丝线物流智能监控与多模态预警平台**

在原项目（视觉识别 + 激光雷达的制丝线物流监视系统，已完成硬件验收，2025-05 上线）基础上，建设一套
**可视化监控 + 多模态融合 + 提前预警 + 报警溯源 + 知识积累** 的完整平台。

核心升级：由「异常发生 → 检测 → 报警」升级为「持续观测 → 多模态融合 → 趋势变化 → 风险预测 → 提前预警 → 人工干预」。

原始项目正式名称（文档口径）：**《视觉识别及雷达技术在制丝线物流监视的研究与应用》**
承担单位：xx 卷烟厂制丝车间（第一承担）、重庆邮电大学（外协，提供激光雷达、算法、可视化平台）。

## 3. 硬件与技术参数（来自 `报告.doc`，实现仿真时必须一致）

- **激光雷达 ×3**：品牌"重邮自研"（重庆邮电大学），测距 **0.1–40 m**，精度 **±5 cm**，刷新率最高 **1000 Hz**，IP65，工作温度 −20~60 ℃，供电 DC 5 V，尺寸 69×41.5×26 mm。
- **网络摄像机 ×15**：海康威视 DS-2CD2242CX8-L，400 万像素，红外夜视，H.265，IP67，最低照度 0.01 Lux，25 fps，−30~60 ℃，DC 12 V / PoE，约 117×87×81 mm。
- **显示器 ×1**：海康威视 DS-D5242FI-1V2，42″，1920×1080，500 cd/m²，对比度 4000:1。
- **硬盘录像机 ×1**：海康威视 DS-8616NI-K8-V2，7×8 TB，16 路 IP 接入，160 Mbps，H.265，8×SATA，双 HDMI。
- **PoE 交换机 ×3**：海康威视 DS-3E0508SP-S，8 口百兆 PoE，单口 30 W，总 PoE 58 W，802.3af/at。
- **汇聚交换机 ×1**：海康威视 DS-3E2728T-H(B)，28 口千兆管理型，VLAN/QoS/环网，背板 56 Gbps。

**数据采集**：雷达与摄像头均 PoE 供电+传输，采集频率 **10 Hz**，持续采集，**不与车间集控系统交互**（不得影响集控系统）。

**参数异常判断规则**：雷达阈值可自行配置；视频经 AI 模型训练后自动判断；同时配雷达+摄像头的点位做联合判断，仅配其一则单独判断。

**报警内容**：设备名称 + 设备IP + 报警时间 + 距离信息。
**报警查询**：按时间段、设备名称查询。
**报警详情**：可点击查看异常分析窗口 → 时间走向曲线 + 对应图像数据。
**维护方式**：更新维护报警点阈值信息即可。

## 7. 关键数据字段口径

- **实时样本**：`ts`、`sim_state`(normal/attention/warning/alarm/stopped)、`radar{distance, baseline_distance, delta, refresh_hz, online}`、
  `vision{status, label, confidence, coverage}`、`environment{temperature, humidity}`、`conveyor{speed}`、`risk{index, level, trend}`。
- **风险等级**：`low`(<30) / `medium`(30–55) / `high`(55–80) / `critical`(≥80)。
- **报警等级**：提示(info，绿/灰蓝) / 预警(warning，橙) / 严重(critical，红)。
- **报警字段**：报警 ID、时间、设备、IP、位置、类型、等级、雷达值、视觉结果、联合结果、处理状态。
- **knowledge_event 字段**：id、event_code、timestamp、device_id、location、event_type、radar_summary、vision_summary、
  environment_summary、pre_event_pattern、operator_review、action_taken、result、preventive_suggestion。
- **处理闭环**：发现 → 判断 → 报警 → 处理 → 归档。

## 8. UI 风格（强制）

工业监控风：白底为主、绿色主强调、深灰文字、少量蓝灰辅助；**红=严重报警，橙=预警，绿=正常**。
布局：顶部栏 + 左侧导航 + 右侧主工作区，桌面优先（1920×1080 与常规笔记本），基本响应式。
禁止：紫色渐变、霓虹、Cyberpunk、大面积深色、AI SaaS 风、过度毛玻璃/圆角、花哨动效。目标是"企业真实生产监控系统"。

## 9. 当前约束

- 无真实硬件连接 → **真实系统架构 + 高仿真演示数据 + 视频模拟实时监控**；不伪造真实硬件连接代码。
- 数据必须符合工业逻辑：状态机驱动、时间序列连续、指标互相关联；**禁止 Math.random() 乱跳**，刷新不得出现无关数据。
- 监控视频仍在生成中 → 固定约定 `frontend/public/videos/main-monitor.mp4`，缺失时自动 fallback 到静态监控图，**不得因缺视频报错/白屏**。
- 数据库只用 SQLite；不引入 Milvus / Elasticsearch / Kafka / Redis Cluster / 向量库。
- 依赖从简：一个功能一个依赖前先问"是否真的需要"。

## 10. 技术栈（已定）

- 前端：React 18 + Vite + TypeScript + ECharts，自写工业风组件与设计令牌（不引组件库）
- 后端：FastAPI + Uvicorn（Python 3.12，conda 环境 `smoking`）
- 数据库：SQLite（stdlib `sqlite3`）
- 部署：Nginx 静态 + `/api/` 反代 Uvicorn（systemd 或 user systemd / tmux）
