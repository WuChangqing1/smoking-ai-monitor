技术要求查验
1、数据采集源
本系统的激光雷达和摄像头采用POE供电和数据传输，采集各制丝线物流的实时数据，数据采集频率为10Hz，本系统不与车间集控系统交互，不影响车间集控系统的正常运行。
2、数据采集规则
本系统的雷达数据和视频数据自系统运行即开始采集，持续进行，数据采集频率为10Hz。
3、参数异常判断
激光雷达的参数异常判断逻辑可根据需要自行配置，视频数据通过AI模型训练后可自动完成判断；同时配备激光雷达和摄像头的监控点将进行联合判断，若仅配备其中之一，则采用相应的单独判断方式。
4、报警内容
单次报警的内容包括：设备名称 + 设备IP + 报警时间 + 距离信息。
5、报警记录的查询
可按时间段、设备名称、对报警内容进行查询，列出的内容包括：设备名称 + 设备IP + 报警时间 + 距离信息；
6、分析窗口
在参数报警的同时，对应的报警点可点击查看异常分析窗口，窗口内容主要对数据在时间上的走向以及对应的图像数据。
7、本系统操作维护简便，更新维护报警点的阈值信息即可。
综上查验，视觉识别及雷达技术在制丝线物流监视的研究与应用达到技术要求。
