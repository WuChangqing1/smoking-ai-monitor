两个技术重点

答辩演示的核心看点

一、画面与数据严格同步

页面数值不是按“网页运行了多少秒”变化的，而是实时读取监控画面的播放位置解算出来的。 因此画面暂停、切换标签页、拖动进度、循环重播，数据都跟着画面走，不会跑偏。

二、视觉异常检测与证据链

画面进入预警阶段后，在物料堆积区域叠加一个固定位置的异常区域框； 同时生成带框证据图，接入报警详情与数据溯源，作为现场复核依据。

03

技术实现要点

低依赖 · 可验证 · 可扩展
方面做法
前端 React 18 + Vite + TypeScript，手写工业风组件与设计令牌，不引入组件库；唯一重依赖是 ECharts
后端 FastAPI + Uvicorn，SQLite 使用标准库 sqlite3；10 Hz 后台采样线程，历史接口降采样输出
数据一致性 后端是权威定义，前端做等价实现；101 个时间点 × 6 个字段逐点比对通过，防止两边漂移
确定性 所有演示数值由时间推导，不使用随机数；同一时刻重复计算结果完全一致，适合录屏与答辩
无真实推理 检测框是展示层的异常可视化，不加载模型权重、不引入推理依赖（有测试断言防止误加）
扩展性 检测配置按机位编号组织，新增摄像头只需追加配置，解析逻辑与页面代码不动
稳定性 视频缺失自动回退静态画面、后端断开保留末次数据并提示、页面级错误边界，不出现白屏
